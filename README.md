# Grade Calculator (Python CLI)

A small command-line tool that reads student scores, calculates the average and prints a letter grade (A-F). Scores must be numbers between 0 and 100.

## How to run

1. Install Python 3.10 or newer.
2. Clone this repository and open it in PyCharm.
3. Right-click `grade_calculator.py` -> Run.
4. Type scores separated by spaces, for example: `80 90 100`.

## Run the tests

Right-click `test_grade_calculator.py` -> Run, or use `python -m unittest`.
